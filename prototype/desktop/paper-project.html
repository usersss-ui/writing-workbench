登记一个论文项目

在本机配置目录新建 local_library_config/paper-projects.local.json：

{
  "version": 1,
  "projects": [
    { "project_id": "p03", "path": "/论文项目目录的绝对路径", "layout": "paper-writing-workflow" }
  ]
}

保存后刷新本页即可，不需要重启服务。该文件不进 git，也不在公开包内。
