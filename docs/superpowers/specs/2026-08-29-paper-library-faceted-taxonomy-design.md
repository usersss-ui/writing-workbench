# 论文库正交分面标签设计

## 目标

把当前由“研究方向 + 论文专属组合词”组成的标签系统，改成可自由组合的基础分面。用户应能用若干独立条件定位论文，例如：

```text
时变网络 AND 非一致本地约束 AND 单点估计 AND 差分隐私
```

系统不得再依靠“耦合约束对偶分解”“隐私约束零阶优化与联邦学习”等复合字符串表达多个概念。

## 内容边界

- 继续以稳定 `paper_id` 关联标签，不依赖文件夹路径分类。
- 不移动、不改名、不覆盖 `/Users/yangfan/Desktop/papers/论文/` 中的 PDF、OCR、笔记、代码和结果。
- `paper-index.json` 仍是可重建的生成产物；标签事实保存在本地配置层。
- 原文中出现的算法名称和作者术语可以搜索，但不自动成为通用筛选项。
- 只有显式目录标签、已有结构化笔记或已核验原文能够支持细粒度标签。依据不足时保持空值，并显示“待核验”，不得从文件夹名、题名或相邻论文猜测。

## 设计原则

1. 一个筛选项只表达一个概念。
2. 同一小组中的选项为 OR，不同小组之间为 AND。
3. 需要同时满足的两个条件必须位于不同小组，不能预先拼成复合标签。
4. 论文专名、算法缩写和章节名称进入搜索别名，不进入通用分类。
5. 文献类型、阅读进度与学术内容标签分开管理。

## 数据结构

标签目录升级为版本 2。每篇记录使用嵌套 `facets`，不再持续增加含义重叠的顶层数组：

```json
{
  "version": 2,
  "papers": {
    "Falsone17-DD": {
      "facets": {
        "research": {
          "domain": ["分布式优化"],
          "mode": []
        },
        "objective": ["凸"],
        "constraints": {
          "scope": ["耦合约束"],
          "form": ["不等式约束"],
          "consistency": []
        },
        "oracle": {
          "information": ["次梯度"],
          "estimation": []
        },
        "methods": {
          "framework": ["对偶分解"],
          "coordination": [],
          "operator": ["近端"]
        },
        "network": {
          "direction": ["无向"],
          "time": ["时变"],
          "balance": [],
          "mixing": []
        },
        "privacy_robustness": [],
        "results": [],
        "applications": []
      },
      "source_terms": ["Dual Decomposition", "Proximal Subgradient"]
    }
  }
}
```

`source_terms` 只用于搜索和详情展示。旧字段在迁移期间可以读取，但不再参与新筛选器；完成迁移后，生成索引只输出新分面和必要的兼容显示字段。

## 受控分面

### 研究任务

- `research.domain`：分布式优化、分布式学习、联邦学习。
- `research.mode`：静态优化、在线优化、随机优化、鲁棒优化。

“约束优化”和“零阶优化”不再作为研究方向：前者由约束分面表达，后者由梯度信息分面表达。

### 目标函数

`objective` 使用原子性质：凸、强凸、非凸、光滑、非光滑、随机目标。

“平滑强凸”拆成“光滑 + 强凸”，“在线凸优化”拆到 `research.mode` 和 `objective`。

### 约束结构

- `constraints.scope`：无显式约束、本地约束、耦合约束、决策耦合约束。
- `constraints.form`：集合约束、等式约束、不等式约束、不确定约束。
- `constraints.consistency`：本地一致约束、本地非一致约束。

等式和不等式同时存在时分别保存两个标签，不创建“等式与不等式耦合约束”。“一般约束”只有在能够核实具体形式后才替换，否则该细分面留空并标记待核验。

### 梯度与反馈

- `oracle.information`：精确梯度、次梯度、随机梯度、函数值反馈。
- `oracle.estimation`：梯度跟踪、单点估计、双点估计、残差反馈、次梯度重缩放。

“近端跟踪”拆成 `methods.operator: 近端` 与 `oracle.estimation: 梯度跟踪`；原术语保留在 `source_terms`。

### 方法体系

- `methods.framework`：次梯度法、对偶平均、镜像下降、对偶分解、ADMM、原始—对偶、增广拉格朗日、算子分裂、原始松弛。
- `methods.coordination`：普通共识、Push-Sum、Perron 修正、动态跟踪、有限时间共识。
- `methods.operator`：投影、近端、预测—校正、Nesterov 加速。

`Tracking-ADMM` 拆成“ADMM + 动态跟踪”；`Tseng Splitting` 保留为搜索术语，同时映射到“算子分裂 + 预测—校正”。

### 网络条件

- `network.direction`：有向、无向、中心化服务器。
- `network.time`：固定、时变。
- `network.balance`：平衡、不平衡。
- `network.mixing`：行随机、列随机、双随机。

Push-Sum 和 Perron 修正属于协调机制，不与网络拓扑混在同一分面。

### 隐私、理论与应用

- `privacy_robustness`：差分隐私、Laplace 机制、Gaussian 机制、安全多方计算、结构化扰动、拜占庭鲁棒、不确定性鲁棒。
- `results`：渐近收敛、精确收敛、线性收敛、次线性收敛、静态遗憾、动态遗憾、约束违反界、隐私保证、鲁棒保证、通信复杂度。
- `applications`：车联网、无线物联网、临床机器学习、工业信息物理系统，以及以后确有多篇文献复用的应用标签。

路径变化量、步长条件、约束正则性等属于理论条件或上界依赖，只在详情中展示，不冒充理论结论。

## 非科研字段

- `record_type`：外部论文、学位论文、学位论文章节、专题综述。
- 阅读状态、原文核验、证据结构、仿真复现继续使用现有状态字段，并统一放入“材料进度”。

章节标题、作者研究线和旧目录主题只作为导航或来源说明，不进入学术筛选。

## 筛选界面

默认显示五个入口：

```text
研究任务｜约束结构｜梯度与反馈｜方法体系｜更多条件
```

- “研究任务”包含研究领域、任务范式。
- “约束结构”包含作用范围、数学形式、节点一致性。
- “梯度与反馈”包含信息来源、估计与跟踪方式。
- “方法体系”包含主框架、协调机制、更新算子。
- “更多条件”包含网络、目标函数、隐私与鲁棒、理论结果、应用领域和记录类型。

每次只展开一个面板。已选条件在结果列表上方显示为可删除标签，并显示各自命中数量。取消当前把全部复选框塞进固定高度内部滚动区的布局。

筛选语义：

- 同一小组内 OR，例如“等式约束 + 不等式约束”表示命中任一形式。
- 不同小组间 AND，例如“耦合约束 AND 不等式约束 AND 对偶分解”。
- 暂不提供任意布尔表达式；若后续确有需求，只为方法体系增加“任一/全部包含”高级选项。

## 搜索与详情

搜索覆盖：标题、作者、`paper_id`、所有基础分面、`source_terms`。搜索结果应指出命中的是通用标签还是原文术语。

论文详情页使用“论文研究画像”展示：研究任务、目标函数、约束结构、梯度与反馈、方法体系、网络条件、隐私与鲁棒、理论结果、应用领域。原文术语单独折叠展示。

## 迁移规则

1. 停止把 `topic_l1`、`topic_l2` 与 `research_scopes` 合并为“研究方向”。
2. `topic_l2` 仅保留为旧目录定位或搜索别名，不再产生筛选选项。
3. 以当前49条稳定记录为迁移全集；此前明确排除的连续时间论文保持排除。
4. 优先使用目录显式标签和已有结构化笔记拆分复合标签。
5. 只有 PDF 的论文先建立能够直接确认的基础分面；无法确认的约束一致性、理论速率和细化机制留空。
6. 迁移审计必须列出每篇论文的旧标签、新分面、拆分来源和待核验项。
7. 新增论文如果没有标签仍可进入论文库，但显示“待标注”，不进入任何学术分面结果。

## 验收标准

- “研究方向”不再显示论文专属组合词、章节名称或应用领域。
- 当前49条记录全部迁移到版本2标签目录，稳定 ID 无重复、无遗漏、无未知 ID。
- 每条记录至少具备 `record_type` 和一个已确认的研究任务或“待标注”状态。
- 能正确筛选代表组合：
  - 耦合约束 AND 不等式约束 AND 对偶分解；
  - 本地非一致约束 AND 时变网络；
  - 函数值反馈 AND 单点估计 AND 在线优化；
  - 差分隐私 AND 联邦学习。
- 原文术语可搜索，但不会出现在通用筛选项中。
- 旧复合标签不进入新生成索引的分面值。
- 论文详情页能逐组展示研究画像和待核验项。
- 1280×720 与1440×900下筛选入口、展开面板、已选标签和结果列表均可操作且无水平溢出。
- 构建、单元测试、端到端浏览器验收与私有路径审计全部通过。
- 原始 PDF、OCR、笔记、代码和结果未被移动、覆盖或修改。

## 不在本轮范围

- 不建立任意布尔查询语言。
- 不自动评价论文创新性或贡献强弱。
- 不从标签直接推断证据已核验、代码已复现或理论结论正确。
- 不重排原始论文文件夹，也不修改私人 Markdown frontmatter。
- 不安装依赖、不发布网站、不提交 Git。
