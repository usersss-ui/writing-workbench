# 论文库标签统一设计

## 目标

为本地论文库中的每条稳定 `paper_id` 建立可筛选的中文结构化标签，使分类不再依赖旧目录层级，同时保留现有 PDF、OCR、笔记、代码和结果文件的位置。

## 数据边界

- 不移动、不改名、不覆盖 `/Users/yangfan/Desktop/papers/论文/` 内的任何材料。
- 标签来源仅限 `1.目录.md` 的显式标签、论文题名、已有笔记/知识库以及必要时可核验的 PDF 内容。
- 标签保存在本地工作台配置层，并通过稳定 `paper_id` 关联；文件夹路径不作为研究方向事实来源。
- 生成的 `paper-index.json` 只是构建产物。

## 标签轴

每条论文记录保留主方向 `topic_l1/topic_l2`，并支持六个可多选的标签轴：

1. `research_scopes`：研究方向，如分布式优化、在线优化、零阶优化、联邦学习。
2. `method_tags`：算法与机制，如梯度跟踪、Push-Sum、原始-对偶分裂、残差反馈。
3. `network_tags`：网络与通信条件，如有向网络、时变网络、不平衡网络、行随机矩阵。
4. `problem_tags`：问题与约束，如非一致约束、耦合约束、强凸优化、非凸优化。
5. `property_tags`：性质与目标，如差分隐私、鲁棒性、通信高效、拜占庭鲁棒。
6. `theory_tags`：已明确报告的理论结果，如线性收敛、静态遗憾、动态遗憾、约束违反。

`contribution_role` 与 `p02_relevance` 不在本轮自动填充。它们包含评价性判断，不能只由题名或关键词推出。

## 行为

- 标签配置按 `paper_id` 合并到扫描结果，并记录 `tag_catalog` 来源。
- 当前 49 条包含记录必须都有非空主方向与至少一个研究方向标签。
- 新增论文即使暂未标注也仍可进入库，但审计报告必须显示“待标注”，不能静默归类。
- 搜索覆盖新增的性质和理论标签；筛选区新增“性质标签”和“理论结果”。
- 论文详情页展示六个标签轴。
- 所有筛选仍是同轴内 OR、跨轴 AND。

## 验收

- 49 条当前记录均有稳定中文标签，且待标注数为 0。
- 目录中被明确排除的连续时间论文仍不进入库。
- 标签配置不存在未知字段、重复标签、空白标签或未匹配 `paper_id`。
- 构建、单元测试、私有库端到端检查通过。
- 论文列表能按性质和理论结果筛选，搜索可命中这些标签。
- 生成内容不包含私人绝对路径。
